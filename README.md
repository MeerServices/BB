# Bonnenbak

Web-app om kassabonnen te fotograferen, te bewaren met wie, reden, project en pas, en te delen via WhatsApp of e-mail.

- Online: https://meerservices.github.io/BB/
- Op je telefoon: open de link in Chrome of Safari en kies **Toevoegen aan startscherm**.
- Bonnen worden nu bewaard op het apparaat zelf (IndexedDB). Opslag in Google Drive en Dropbox volgt.

Geen build-stap: `index.html`, `style.css` en `app.js` worden zo gepubliceerd via GitHub Pages (`.github/workflows/pages.yml`).
